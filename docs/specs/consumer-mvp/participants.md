# Consumer QR 참여 인원 규약

> 상위 문서: [Consumer MVP API 문서 허브](../consumer-mvp-api-spec.md)  
> 실시간 연결: [SSE 운영 가이드](../../guides/sse-guide.md)

## 목적

Consumer 헤더의 `N명 이용중`은 테이블 좌석 수나 주문 인원이 아니라, 현재 같은 방문의 QR 화면에 연결된 고유 브라우저 세션 수를 표시한다.

## 확정 기준

- 참여자 한 명은 하나의 서버 `HttpSession` ID다.
- 같은 일반 브라우저에서 탭을 여러 개 열어도 한 명으로 계산한다.
- 일반 창과 시크릿 창은 서로 다른 세션이므로 각각 한 명으로 계산한다.
- 다른 브라우저와 다른 기기도 각각 한 명으로 계산한다.
- 주문 생성 여부는 참여 인원에 영향을 주지 않는다.
- SSE 연결이 살아 있는 동안 참여 상태를 유지한다.
- 마지막 탭의 SSE 연결이 종료되면 해당 브라우저 세션을 참여자에서 제거한다.

## 동작 흐름

1. Consumer 화면이 `GET /api/client/consumer/events`에 연결한다.
2. 서버가 현재 방문 채널에 HTTP 세션 ID를 등록한다.
3. 방문 채널의 고유 세션 수를 계산한다.
4. 서버가 모든 연결에 `PARTICIPANTS_CHANGED` 이벤트를 보낸다.
5. 프런트가 이벤트 숫자를 저장하고 헤더를 다시 렌더링한다.
6. 연결 완료/오류/시간 초과 시 서버가 해당 연결을 정리하고 남은 수를 다시 보낸다.

## SSE 계약

```text
event: PARTICIPANTS_CHANGED
data: 2
```

- payload는 1 이상의 정수다.
- 연결 직후 현재 인원을 한 번 전송한다.
- 참여 또는 이탈할 때마다 같은 방문의 모든 연결에 전송한다.
- 프런트는 잘못된 값, 소수와 1 미만의 값을 무시한다.
- 첫 이벤트 전에는 현재 화면을 포함해 `1명 이용중`으로 표시한다.

## 구현 위치

### Backend

- `ConsumerParticipantRegistry`: 방문별 HTTP 세션과 탭 연결 수를 메모리에 관리한다.
- `ConsumerEventService`: SSE 연결/해제 시 참여자를 등록/제거하고 이벤트를 발행한다.
- `SSEEmitterService`: 연결 종료 콜백을 한 번만 호출한다.

### Frontend

- `consumerParticipantStore`: 최신 참여 인원을 보관한다.
- `useConsumerEvents`: `PARTICIPANTS_CHANGED`를 수신한다.
- `ConsumerHeader`: 기존 `tableQty` 대신 참여 인원을 표시한다.

## 선택 이유

- 기존 Consumer SSE 연결이 현재 QR 화면의 활성 상태를 이미 나타낸다.
- 실시간 상태이므로 주문/결제 데이터처럼 DB에 영구 보관할 필요가 없다.
- HTTP 세션 ID로 중복 탭을 제거할 수 있다.
- 별도 polling API 없이 참여/이탈을 즉시 반영할 수 있다.

## 운영 한계

- 참여자 저장소는 서버 메모리에 있으므로 단일 애플리케이션 인스턴스에서만 정확하다.
- 서버가 재시작되면 집계가 초기화되지만 브라우저가 SSE를 재연결하면서 다시 등록된다.
- 비정상 네트워크 단절은 서버가 오류 또는 heartbeat 실패를 감지한 뒤 반영된다.
- 다중 서버 운영 전에는 Redis 같은 공용 저장소와 인스턴스 간 이벤트 전달이 필요하다.
- 현재 정책은 실제 사람 수가 아니라 QR을 연 고유 브라우저 세션 수다.

## 수동 QA

1. 백엔드를 재시작하고 일반 창으로 QR을 열어 `1명 이용중`을 확인한다.
2. 같은 QR을 시크릿 창에서 열어 양쪽이 `2명 이용중`으로 바뀌는지 확인한다.
3. 일반 창에 탭을 하나 더 열어도 `2명`이 유지되는지 확인한다.
4. 시크릿 창을 닫고 일반 창이 `1명 이용중`으로 돌아오는지 확인한다.
5. 주문하지 않은 상태에서도 1~4가 동일하게 동작하는지 확인한다.
6. 개발자도구 Network의 event stream에서 `PARTICIPANTS_CHANGED`와 숫자 payload를 확인한다.
