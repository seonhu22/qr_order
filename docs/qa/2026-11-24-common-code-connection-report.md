# 공통코드 연결 현황 보고 / CODE-00

2026-11-24 작업 트리 기준으로 Admin / Client / Consumer 라우트와 하위 모달/필터/표시 라벨을 정적 조사했다. 표에서 서버 검증은 코드 허용값 검사, 쿼리 필터, 응답 변환을 각각 명시한다. 실서버 호출과 운영 DB의 활성 마스터/상세 데이터는 확인하지 않았다.

- **연결 완료**는 화면이 공통코드 콤보 또는 공통코드 관리 API를 조회하는 경우다. **하드코딩**은 선택값이나 라벨을 화면 코드에서 정하는 경우다. **미연결**은 공통코드 조회 또는 업무 저장 경로가 없는 경우다. 다른 업무 API가 이미 연결된 항목은 괄호에 표시했다. **사용자 코드 등록 필요**는 관리자가 상세 코드를 먼저 등록해야 입력을 저장할 수 있는 경우다.
- ComboController의 `GET /api/combo/common?code=…`은 마스터/상세 모두 사용 중이고 삭제되지 않은 행의 코드와 명칭을 반환한다. 검색용 `/api/search_combo/common`은 전체 선택지를 추가하며 세 앱의 운영 코드에서 호출을 찾지 못했다. 사업장 콤보는 `sys_plant` 조회다.
