- E2E-01 / 부분 완료. 모의 API 브라우저 회귀와 실제 서버 기본 권한/카드 결제 스펙에 더해, 로컬 사본 DB에서 로그인 폼/권한/초기화(3개), 주문 수정/취소/미결제/정산 조회와 양방향 SSE(2개), 문의/사업장/공지와 호출 재검증(3개)이 통과했다. 결제 원장과 SSE 재연결 복구 자동화 및 팀 서버 검증은 대기다. [인증 QA](../qa/2026-11-24-local-real-qa-auth.md#재검증-2026-11-24) / [주문 QA](../qa/2026-11-24-local-real-qa-ops.md#e2e-01) / [운영 재검증](../qa/2026-11-24-local-real-qa-ops.md#재검증-2026-11-24)
- 실행은 지정한 테스트 매장/계정으로 제한한다. 로그인 후 역할/매장을 확인하고 일치하지 않으면 쓰기를 중단한다. 생성 데이터는 `AUTO-QA`와 실행 식별자 또는 테스트 매장/실행 기록으로 추적한다. 계정 값은 Git에서 제외된 로컬 환경변수로 전달하고 DB 초기화는 별도 합의한다. 비밀번호는 채팅/커밋/실행 로그에 남기지 않는다. 식별 방법이 없는 쓰기는 실행 전에 확인한다. 초기 실행은 순차 실행/최소 재시도로 하고, 대량 실행 전 예상 작업량을 알리며 반복 서버 오류/지연 시 중단한다. [실행 안내](../../frontend/docs/testing/real-server-qa.md)
- Client 카탈로그, Admin 메뉴 루트와 초기 비밀번호는 로컬 환경 보정 후 확인했다. 팀 서버의 설정과 DB 시드는 별도 확인 범위다. [환경 보정](../qa/2026-11-24-local-real-qa-env.md)
