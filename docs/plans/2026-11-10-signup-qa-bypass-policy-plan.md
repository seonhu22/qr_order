# 사업자 인증 QA 우회 유지 조건 갱신

## 근거와 범위

- 사용자 결정: 테스트 사업자 데이터 확보 전까지 우회를 유지한다(2026-11-10).
- 기존 문서에는 4주 경과 제거 조건이 있지만 런타임에는 날짜 만료가 없다.
- [정책 문서](../../frontend/docs/qa-bypass-business-verification.md)를 제거 기준의 기준 문서로 사용한다.
- 백엔드/DB/API/환경변수 계약과 실행 로직은 변경하지 않는다.

## 구현 순서

1. 4주 제거 조건을 폐기하고 테스트 데이터 또는 NTS mock으로 우회 OFF 가입 QA 통과 후 제거하도록 기록한다.
2. 유틸과 호출부 TODO를 같은 조건으로 동기화한다.
3. 기존 DEV/명시적 true/HTTP 400 AND 조건을 유지하고 미설정 플래그/403/네트워크 오류 회귀 테스트를 보강한다.
4. 관련 테스트/typecheck/lint/diff 검사로 확인한다.

## 검토 기준

- 플랜 담당과 검토 담당의 피드백을 반영한다.
- 근거 없이 production 번들 완전 제거를 주장하지 않는다. 이번 범위는 DEV=false 판정 및 호출부 실행 차단이다.
- dev:real 가입 QA 미수행을 명시하고 제거 전 사업자 인증/이메일 인증/최종 가입 검증을 요구한다.
- QA 가짜 데이터 정리 주의와 완료 기록 추적성을 유지한다.
- 기존 백로그 문서의 사용자 변경은 이번 커밋에서 제외한다.

## 완료 조건

- 문서/주석의 종료 조건이 일치하고 위 자동 검사가 통과한다.
- DB부터 transport까지의 계약 변경은 없어 교차 계층 변경 게이트는 해당 없음.
- 실서버 가입 QA와 Notion 동기화 여부는 완료 보고에서 별도로 명시한다.
