# 콤보 API 사용 기준

> 작성일: 2026-06-09

## 핵심

콤보 박스는 화면에서 같은 `select`처럼 보여도 목적이 다르다.

- 검색용 콤보: 조건을 걸거나, 걸지 않기 위한 선택
- 저장용 콤보: 실제 DB에 저장할 값을 고르기 위한 선택

## API 구분

| API | 용도 | `전체` 포함 |
| --- | --- | --- |
| `/api/search_combo/common` | 검색 필터용 | 가능 |
| `/api/combo/common` | 등록/수정 저장용 | 불가 |

## 왜 나누는가

`전체`는 실제 저장값이 아니다.

예를 들어 검색 필터에서 `전체`는 “사용여부 조건 없이 전체 조회”라는 뜻이다.

하지만 등록/수정 폼에서 `전체`를 저장하면 “이 데이터의 사용여부가 전체”가 되어 의미가 맞지 않는다.

## 프론트 사용 기준

- 검색 조건 영역: `/api/search_combo/common`
- 등록/수정 모달, 저장 폼: `/api/combo/common`
- 저장 payload에는 `전체`, `ALL` 같은 필터용 값이 들어가면 안 된다.

## QA 체크

- 검색 콤보에는 `전체`가 보이는지 확인
- 저장 폼 콤보에는 `전체`가 없는지 확인
- `전체` 선택 후 검색 시 전체 조회되는지 확인
- 저장 요청 payload에 `전체` 값이 포함되지 않는지 Network 탭에서 확인
